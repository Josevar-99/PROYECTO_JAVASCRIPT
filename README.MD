# LISTA DE NOTAS-GESTION DINAMICA DEL DOM

## DESCRIPCION 
Mini aplicacion web que permite agregar y eliminar notas en tiempo Real,
con persistencia de datos usando Local Storage del navegador.

---

## TECNOLOGIAS UTILIZADAS 
-HTML5
-CSS3
-JavaScript(Vanilla)

---

## ESTRUCTURA DE ARCHIVOS

H2_WK3_JS/
├── manipulacion_dom.html
├──styless.css
├──app.js
└── README.md

---

## Funcionalidades
- Agregar notas escribiendo en el input y presionando **Agregar**
- Eliminar notas individualmente con el botón **Eliminar**
- Las notas se guardan automáticamente en Local Storage
- Al recargar la página las notas persisten

---

## Cómo ejecutarlo
1. Descarga o clona los archivos
2. Abre `manipulacion_dom.html` en tu navegador
3. ¡Listo! No necesita instalación ni servidor

---

## Criterios cumplidos
- `appendChild` y `removeChild` para manipular el DOM
- `getElementById` y `querySelector` para seleccionar elementos
- `textContent` para modificar contenido
- `localStorage.setItem` y `getItem` para persistencia
- Código comentado con uso de `let` y `const`
